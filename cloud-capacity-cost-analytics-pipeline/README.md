# Cloud Capacity & Cost Analytics Pipeline

## Project Summary

This project shows how simulated cloud usage data can be turned into clear cost visibility, capacity planning, and business recommendations.

The goal was to build a small analytics workflow that follows the data from usage records to cleaned data, SQL analysis, dashboard views, and final business insights.

This project uses simulated data for portfolio purposes. No real company data, customer data, or confidential cloud billing data is used.

## Why I Built This Project

Cloud costs can grow quickly when teams only look at spending at the end of the month. By then, it may already be too late to react early.

I built this project to show how data analytics can help a business see cost pressure, capacity growth, and underused resources earlier.

My healthcare background taught me that pressure should be noticed before it becomes a bigger problem. I used that same thinking here, but with cloud usage and cost data.

## Tools Used

- Python
- SQL
- Power BI dashboard mockup
- Data modeling
- Data quality checks
- Business analysis

## Project Workflow

1. Simulated cloud usage data
2. Cleaned and prepared the data with Python
3. Structured the data for SQL analysis
4. Created SQL queries and quality checks
5. Designed dashboard visuals
6. Turned the numbers into business recommendations

## Key Business Questions

- Which cloud services drive the highest monthly cost?
- Where is capacity demand increasing?
- Are there expensive resources with low utilization?
- Which teams or regions need earlier planning visibility?

## Main KPIs

- Total monthly cloud cost
- Monthly cost increase
- Average capacity utilization
- Forecasted compute demand
- High-cost services with low utilization
